So bedienst du es

Encoder: ziehen nach oben/unten, Mausrad oder die Pfeile darunter. EDIT, GLO und ARP rasten auf Wunsch ein (Häkchen oben), dann tippst du sie an, statt sie zu halten. Am Rechner spielen A–K die weißen Tasten ab F3, W E R Z U die schwarzen, Leertaste ist PLAY.

FX SEL ENV LFO
Bereich BEAT, RHYTHM, STRINGS, BASS; nochmal drücken: nächste Klangseite. GLO + Bereich: stumm.
HOME
Übersicht. Weiße Tasten wählen das Pattern, ARP + weiße Taste erzeugt dort einen neuen Groove. EDIT halten: Verzerrung, KNOB 1–4 Sends, PRESETS Typ, ALGORITHM Drive, SELECT Ton.
Links: Struktur
SELECT Pattern. ALGORITHM Tempo, GLO + ALGORITHM Pattern-Länge, EDIT + ALGORITHM Swing (BEAT), Notenlänge (RHYTHM, BASS) bzw. Schrittlänge (STRINGS). PRESETS Sound bzw. in BEAT das Kit.
Rechts: Klang
KNOB 1–4 stellen den Klang ein; in HOME die Pegel der vier Bereiche, deren Tasten direkt darunter liegen.
BEAT
Schwarze Taste wählt und spielt ein Instrument (SEQ: zweite Ebene mit PULSE), weiße Tasten setzen Steps. GLO + SELECT wählt das Instrument, ohne es zu spielen. PRESETS: Kit (auch PO-12).
Synths
Tasten spielen den Sound, SEQ schaltet in den Step-Modus (GLO + SELECT wählt den Step). PRESETS Sound, EDIT + PRESETS andere Engine (MKS-50 / JP-6).
EDIT + Bereich
Synth-Editor für RHYTHM, STRINGS oder BASS (EDIT leuchtet): alle Parameter der Engine in den Sektionen des Original-Panels. SELECT Sektion, ALGORITHM Seite, KNOB 1–4 die vier Regler, PRESETS Sound, EDIT + PRESETS andere Engine. Die Tasten spielen, der Sequencer läuft weiter. Bereichstaste nochmal: zurück. SAVE im Editor speichert den Sound in einen von 32 eigenen Plätzen (PRESETS Platz, KNOB 1 Cursor, KNOB 2 Buchstabe, SAVE nochmal); PRESETS findet sie nach den Werks-Sounds.
ARP halten
Generator: KNOB 1 Stil, KNOB 2 Dichte, weiße Taste = neue Spur.
ARP antippen
In RHYTHM, STRINGS, BASS: Arpeggiator an/aus (eingerastet: zweimal tippen). EDIT + ARP: Hold. Einstellungen auf der Seite ARP (Bereichstaste weiterdrücken): Modus, Rate, Oktaven, Gate.
SAVE
Dann weiße Taste 1–8: Groove in User-Platz 17–24. Gespeichert wird im Browser.
