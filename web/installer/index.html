FM-1 Installer_

Firmware auf das M-VAVE FM-1 aufspielen. Es wird nur das Programm ersetzt, dein Speicher (Sounds, Grooves) wird nicht gelöscht. Alles läuft hier im Browser, nichts geht an einen Server.

Dieser Browser kann kein Web MIDI. Bitte die Seite in Google Chrome oder Microsoft Edge auf einem Computer öffnen (nicht Safari, nicht Firefox).

1FM-1 verbinden

FM-1 einschalten und mit einem USB-Datenkabel an den Computer anschließen. Dann auf „Verbinden“ klicken und den MIDI-Zugriff erlauben.

2Firmware installieren

Während des Schreibens nicht abziehen und das FM-1 nicht ausschalten. Das dauert etwa zwei Minuten.
Fertig
Liste wird geladen …

Wenn etwas schiefgeht

Wurde die Verbindung unterbrochen, bleibt das FM-1 im Update-Modus. Einfach wieder anschließen und bei der Firmware noch einmal „Installieren“ klicken: das Schreiben wird beendet.

Rettungsweg: Startet das FM-1 gar nicht mehr, ausschalten, die Taste OCT − gedrückt halten und einschalten. Es startet dann ohne Ton nur im Update-Modus. Jetzt hier verbinden und eine funktionierende Firmware installieren.

Mehr dazu

Der Installer nutzt dasselbe USB-MIDI-Update (M-UPGRADE) wie das Werkzeug fm1_install.py der Plattform: Die laufende Firmware startet den Update-Lader, der Lader schreibt den Programmbereich, danach startet das FM-1 neu und meldet seine Kennung. Jede Datei wird vorher geprüft (Kennung, Update-Lader im Paket, Prüfsummen); fremde oder beschädigte Dateien werden abgelehnt.

Ob eine andere Firmware die gespeicherten Daten einer vorherigen lesen kann, hängt von der Firmware ab. Gelöscht werden sie beim Installieren nicht.

Zurück zur Original-Firmware von M-VAVE geht mit dem FM-1 Firmware Hub (thefirmwarehub.com). Installieren auf eigene Gefahr.
