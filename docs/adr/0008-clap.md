# 0008: Clap: Ausklang nach dem Original

- **Status:** angenommen (Variante D, Standard)
- **Stand:** 2026-10-29

## Kontext

Unsere Clap ist an Einzelaufnahmen gefittet: Bandpass 1140 Hz (Q 1,95) auf weißem Rauschen, drei lineare Sägezahn-Impulse à 10 ms, ab 30 ms ein Hauptschlag mit 8,7 ms Abfall, darunter eine Fahne von 98 ms bei −11 dB, BA662-Verzerrung (tanh).

Die 8W8-Engine (portiert in X0X-RMX) modelliert die Schaltung:

| | unsere (A) | Schaltung (8W8) |
|---|---|---|
| Rauschen | weiß | einweg-gleichgerichtet: der VCA-Transistor leitet nur eine Polarität |
| Filter | BP 1140 Hz, Q 1,95 | BP 874 Hz, Q 1,29, dann HP 720 Hz |
| Vorschläge | 3 lineare Sägezähne, 10 ms | 3 Impulse auf 0,8, exponentiell τ 4,5 ms, 10 ms Abstand |
| Hauptschlag | ab 30 ms, fällt τ 8,7 ms | öffnet bei 28 ms über 3 ms, fällt τ 38,5 ms |
| Fahne | 98 ms, −11 dB | 330 ms, −30 dB |
| DECAY wirkt auf | Fahne | Hauptschlag und Fahne |

**Messung am Original** (deine Aufnahme „808 Basics Kit A“, Treffer 10 und 12, digitale Stille dazwischen): Nach dem Hauptschlag fällt die echte Clap schnell, bei 160 ms schon 43 dB unter der Spitze. Danach klingt eine sehr leise, **dunkle** Fahne über eine Sekunde aus (−50 dB bei 350 ms, −60 dB bei 900 ms, Schwerpunkt um 1 kHz, Höhen 20–30 dB tiefer). Die Höhen des lauten Teils entstehen im hart angesteuerten VCA; die leise Fahne bleibt sauber und dunkel. Unsere Clap (A) hatte dagegen eine laute (−11 dB), helle Fahne von 98 ms, B und C eine helle bei −30 dB. Das war der Fehler im Ausklang.

Der größte Unterschied zur Schaltung ist der Hauptschlag: bei der Schaltung ein voller, ~4× längerer Körper mit weichem Einsatz statt eines kurzen Abfalls plus getrennter Fahne.

## Entscheidung

Schalter `TR808_CP_MODEL` in `engine/tr808.c` (Standard 0), eigene Umsetzung (`clap_circuit`):

- **A** (0): wie bisher.
- **B** (1): Hüllkurve der Schaltung, unser Filter und Rauschen. Hört man, was die Hüllkurve allein ausmacht.
- **C** (2): zusätzlich Filter und gleichgerichtetes Rauschen der Schaltung.
- **D** (3, **Standard**): an die Aufnahmen gefittet (`host/calibration/fit_clap.py`, `tr808_cp_cal`): Bandpass 1146 Hz, Q 1,5; drei Vorschläge im Abstand 11,4 ms, Abfall 5,5 ms; Hauptschlag bei 33,6 ms, Abfall 32 ms, durch die VCA-Verzerrung; darunter die Fahne: Abfall 0,66 s, Tiefpass 1,2 kHz, ohne Verzerrung. DECAY skaliert Hauptschlag und Fahne, TONE den Bandpass.

Fehler gegen die Aufnahmen (rms dB; Feinhüllkurve 0–120 ms / Ausklang 0–1,2 s / Spektrum in fünf Zeitfenstern):

| Variante | Feinhüllkurve | Ausklang | Spektrum | gesamt |
|---|---|---|---|---|
| A | 8,8 | 7,0–10,4 | 4,0–4,4 | 7,2 |
| B | 4,9–5,7 | 3,9–4,0 | 4,2–4,6 | 4,5 |
| C | 5,5–6,3 | 4,2–4,8 | 4,1–4,8 | 4,9 |
| **D** | 2,5–3,1 | 1,4–1,6 | 2,3–2,7 | **2,3** |

Ausklang in dB unter der Spitze bei 100 / 200 / 400 / 800 ms: Original −27 / −46 / −51 / −56, D −29 / −46 / −51 / −57, A −33 / −41 / −59 / −94. Schwerpunkt 200–600 ms: Original 2,6 kHz, D 2,3 kHz, A 4,1 kHz. Ein zweiter Fit-Durchgang senkte den Fehler nur um 0,17 dB, trieb aber die VCA-Verzerrung von 1,6 auf 5,7: als Überanpassung verworfen.

Pegel angeglichen (`TR808_CP_GAIN1/2`, D über `tr808_cp_cal`): Einzelschläge innerhalb 0,6 dB, im Groove innerhalb 0,1 dB. Gemessen (ein akzentuierter Schlag, ganze Engine mit Sends): −20 dB nach 206 ms (A) / 286 ms (B, C).

## Alternativen

- Nur unsere Fahne verlängern: ändert den Hauptschlag nicht, der den Charakter trägt.
- Fremden Code übernehmen: siehe 0006.

## Folgen

- Nach der Wahl: Standard umstellen, Simulator und Firmware-Testbuild neu bauen, Status auf *angenommen*.
- Nach der Wahl von D: Varianten B und C können entfallen.
- B und C klingen länger; im dichten Groove kann das mehr Platz brauchen (DECAY-Knopf wirkt jetzt auf den Hauptschlag).
- Maracas (SOUND = MARAC) bleiben unberührt.
