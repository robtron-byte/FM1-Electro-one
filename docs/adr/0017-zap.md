# 0017: Zap perkussiv statt tonal

- **Status:** vorgeschlagen (Hörvergleich `build/wav/zap_neu.mp3`: A wie bisher, 1–4 neue Einstellungen)
- **Stand:** 2026-10-29

## Kontext

Rückmeldungen: „Die Zaps sind noch zu tief“, dann zu fünf Tonhöhen-Varianten (höherer Start, weniger Fall): „Sie klingen zu tonal und zu wenig nach Drum, sie gefallen mir alle nicht.“ Der Zap (Modell 0) ist ein reiner Sinus, dessen Tonhöhe fällt (Tune, Sweep, Depth), mit Verzerrung (Tone) und langem Ausklang: nach 100 ms erst 12 dB leiser.

## Entscheidung (vorgeschlagen)

Schalter `TR808_ZP_MODEL` (Standard 0). Modell 1 (`zap_perc`), eigene Umsetzung:

- gleiche Regler: Tune (Start), Sweep (Fallzeit), Depth (Oktaven), Decay;
- unharmonische FM im Anschlag (Verhältnis 1,41, Index fällt in ~6 ms) und ein Rausch-Spritzer durch einen Bandpass, der der fallenden Tonhöhe folgt: überdecken den Ton beim Schlag;
- Decay kürzer (12–270 ms);
- **Tone** = Anteil von FM und Rauschen (0 = sauberer Sweep).

Vier Beispiel-Einstellungen (Parameter Tune / Sweep / Depth / Decay / Tone):

| | Einstellung | nach 100 ms |
|---|---|---|
| A wie bisher | 64 / 50 / 80 / 50 / 30 | −12 dB |
| 1 Laser-Schuss | 96 / 10 / 70 / 40 / 45 | −31 dB |
| 2 Zap-Tom | 72 / 30 / 55 / 60 / 30 | −19 dB |
| 3 Spritzer | 90 / 20 / 60 / 35 / 110 | −35 dB |
| 4 Knall-Zap | 104 / 4 / 90 / 30 / 75 | −39 dB |

Die gewählte Einstellung wird Standard (Werte der Regler), das Modell bleibt für alle einstellbar.

## Vorher verworfen

Nur höher und/oder weniger tief fallend (fünf Varianten, Start 1340–3790 Hz, Ende 63–677 Hz): klingt weiter tonal.
